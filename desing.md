# Design Specifications

## 1. Visual Identity
- **Primary Color:** #16A34A (Green)
- **Background:** #F8F9FA
- **Cards:** #FFFFFF
- **Text:** Primary (#111827), Secondary (#6B7280)
- **Border:** #E5E7EB

## 2. Typography
- **Primary Font:** Inter (fallback: Roboto, Arial, sans-serif)
- **Headings:** Bold (700) for page titles (24-30px), SemiBold (600) for section titles (16-18px).

## 3. UI Components
- **Cards:** White background, 12px border radius, 1px border, subtle shadow.
- **Buttons:** Filled with primary colors, rounded, clear hover states.
- **Badges:** Small, rounded, colored based on status (e.g., In Transit -> Blue, Picked Up -> Green).

## 4. Layout
- **Desktop:** Left sidebar (fixed), Top navbar (fixed), Main content area.
- **Mobile:** Collapsible sidebar (hamburger menu), responsive stacking for grids.
